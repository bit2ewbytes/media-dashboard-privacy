# Media Dashboard App Privacy Policy

**Last updated: September 25, 2026**

Media Dashboard App is a personal media, content, and marketplace-management application.

## Information the application may access

When a user explicitly connects an external service such as eBay, the application may receive information necessary to provide the requested integration, including:

- account or seller identifiers;
- authorization scopes and connection status;
- marketplace account configuration and readiness information;
- listing, inventory, image, policy, and related marketplace information when the user chooses to use those features.

The application does not request or store the user's eBay password.

## OAuth credentials

OAuth access and refresh tokens received from supported services are stored encrypted by the application.

Credentials are used only to perform actions explicitly supported by the connected integration and authorized by the user.

## How information is used

Information obtained through eBay APIs is used only to provide user-requested marketplace-management functionality, such as account connection, listing preparation, inventory management, and related integration features.

The application does not sell personal information or eBay account data.

The application does not use eBay account information for advertising.

## Sharing

The application does not intentionally share eBay user information with unrelated third parties.

Information may be transmitted to eBay when necessary to perform a user-requested eBay operation.

## Data storage and deletion

The application is designed to store operational data within the user's configured application environment.

Users may disconnect an integration and may delete their locally stored application data according to the application's available controls and deployment practices.

Disconnecting an integration locally does not necessarily revoke authorization at the external provider. Users may also manage or revoke application authorization through the applicable provider.

## Security

The application uses reasonable technical safeguards intended to protect integration credentials and data, including encrypted storage of supported OAuth credentials.

No system can guarantee absolute security.

## User control

External-service integrations are initiated by the user.

The application does not publish an eBay offer merely because an eBay account is connected. Marketplace actions require the applicable user-directed workflow.

## Changes to this policy

This policy may be updated as the application's capabilities change. The current version will remain available at this URL.
